📈 Ruang Peta Revenue

Masuk untuk melihat dashboard.

Upload & ubah data hanya untuk akun resmi Alfalee. Tamu bisa melihat seluruh laporan.

Tarik & letakkan file CSV di sini

Bisa dua jenis file sekaligus — dashboard mengenali otomatis. Data bertambah setiap upload (tidak menimpa data lama).

1 · Data penjualan — Scalev → Order → Export → Order with Product (CSV).
2 · Biaya iklan — Meta Ads Manager → Reports → Export dengan breakdown per hari (mis. …(time-daily).csv, ada kolom “Amount spent”). Angka Meta dianggap belum termasuk PPN; dashboard menambahkan PPN 11% otomatis.
3 · Biaya lain (manual) — CSV sederhana: tgl,deskripsi,nilai (opsional kolom ke-4: kategori). Contoh: 15/08/2026,Langganan tools,150000,tools. Nilai dianggap final (tidak ditambah PPN).
4 · Revenue lain (manual) — format sama (tgl,deskripsi,nilai), untuk komisi tiket dan pendapatan di luar produk. Beri kata “revenue” di baris header (mis. tgl,deskripsi,nilai revenue) agar langsung dikenali — kalau tidak, dashboard akan menanyakan file itu biaya atau revenue.

Jika ada order/baris yang sudah pernah diupload, kamu akan diberi tahu jumlah duplikatnya dan memilih sendiri mau melanjutkan atau tidak.
